# NN 설치판 배포

NN 데스크톱 앱의 설치판을 올리는 곳입니다. 앱의 자동 업데이트가 여기 **Releases** 에서 새 판을 받습니다.

- 설치: [Releases](../../releases/latest) 의 `NN Setup <판>.exe` 를 내려받아 실행합니다(Windows).
- 업데이트: 설치한 NN 이 켤 때 · 몇 시간마다 새 판을 확인하고 뒤에서 받아 둡니다. **끌 때** 설치됩니다.
- 서명이 아직 없어 처음 설치할 때 Windows SmartScreen 경고가 뜰 수 있습니다(「추가 정보 › 실행」).

소스 코드는 이 저장소에 없습니다.
